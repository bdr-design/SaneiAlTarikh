# Cost lines (L12, P2)

Every feature has a line here: what it costs on the phone, on which engine (ADR 0001), and how it is measured. The
measured columns come from the in-app recorder's CSV on the owner's iPhone (§3.8), never from a simulator or a browser.
"—" means not measured yet.

M0 measured on the owner's iPhone 17 Pro Max (iPhone18,2, iOS 27.0.1), 2026-11-09: thermal nominal throughout. Files:
`docs/measurements/m0/` (the recorder CSV, `ring.log`, `device.txt`). The CSV's memory column is
`os_proc_available_memory`, the headroom to the app's limit, not free memory: 6,654 MB at launch, 6,626–6,627 MB idle, 6,591
MB when the load began, 6,596 MB after; the app grew about 63 MB from launch to load. Second build: 6,626–6,627 MB idle and 6,591–6,596 MB under load in run 1; 6,620–6,621 MB idle and 6,595 MB under load in run 2. Third build: 6,626–6,627 and 6,591–6,596 MB in run 1; 6,620–6,621 and 6,595–6,596 MB in run 2. L8's `phys_footprint` budget is not
measured yet (it joins the recorder with M0b).
