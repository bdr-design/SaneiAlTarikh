# صانع التاريخ

لعبة استراتيجية عالمية للآيفون، من 1 يناير 2011 إلى 2100. تُكتب بلغة Swift، وتُلعب بالوضع الأفقي، وواجهتها بالعربية.

## المرحلة الحالية: التصميم والاتفاق
لا يوجد كود للعبة بعد. كل شاشة تُصمَّم ويعتمدها صاحب المشروع قبل أن تُبنى.

| المجلد | المحتوى |
|---|---|
| `decisions/` | القرارات المتفق عليها (`decisions.json`) وسجل الاعتمادات (`decisions_log.txt`) |
| `design_doc/` | وثيقة التصميم التقني للمحرك (`final_design.md`) |
| `design/screen1/B3` | شاشة اللعب، **معتمدة** |
| `design/screen2/B` | القائمة الرئيسية، **معتمدة** |
| `design/screen3/` | صفحات «لعبة جديدة» الثلاث، **قيد التهيئة لكل الأجهزة** (انظر `tasks/T-001_screen3_fit.md`) |
| `design/shared/` | الخرائط والأعلام وصور السيناريوهات وموجز كل شاشة |
| `design/generated/` | الصور المولّدة للعبة |
| `research/` | أبحاث البيانات والأداء والواقعية |
| `tools/` | سكربتات بناء الخرائط وعرض الشاشات وفحصها |
| `wf/` | سكربتات القياس التي تستند إليها أرقام وثيقة التصميم |
| `PROCESS.md` | آلية العمل الملزمة |
| `WORKLOG.md` | سجل ما أُنجز وما بقي |

## ملاحظة عن الصور
الصور في `design/screen*/` نماذج HTML معروضة في Chromium بمقاسات الآيفون. **ليست اختبارًا على آيفون حقيقي.**

## إعادة عرض شاشة وفحصها
```sh
cd tools && npm install
cd ../design/screen2/B/_build && NODE_PATH=../../../../tools/node_modules node render.js
python3 -I ../../../../tools/check_screen.py ../../../../design/screen2/B
```

## الحقوق
- كل الحقوق محفوظة لصاحب المشروع في عمله الخاص.
- البيانات والصور الفضائية والخطوط والأعلام من أطراف أخرى، وتبقى بتراخيصها. بعضها ملك عام، والتفاصيل في `CREDITS.md`.
