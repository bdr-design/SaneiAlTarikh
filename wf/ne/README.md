# Natural Earth inputs (not stored here)

The measurement scripts in `wf/` read these public-domain Natural Earth layers, converted to GeoJSON:
- `ne_10m_admin_0_countries`
- `ne_50m_admin_0_countries`
- `ne_10m_admin_0_map_units`
- `ne_10m_admin_0_disputed_areas`
- `ne_10m_admin_0_antarctic_claims`
- `ne10_admin1` (admin-1 states and provinces)
- `ne_10m_populated_places`
- `ne_10m_lakes`
- `ne_10m_rivers_lake_centerlines`
- `ne_10m_geography_regions_polys`

Source: https://www.naturalearthdata.com (also mirrored at github.com/nvkelso/natural-earth-vector).
